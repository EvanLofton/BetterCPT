# BetterCPT Dashboard 规范

> Phase 4 开发前置文档。包含功能清单和 UI 设计稿。
> 技术栈：Tauri v2 + React + TypeScript + Vite + Tailwind CSS
>
> **架构决策（2026-05-19）**：Dashboard 运行在 Host 进程内，非独立进程。
> Tauri 直接嵌入 Host，Rust 后端通过 `State<Arc<RuntimeRegistry>>` 访问状态，零 IPC。
> 详见 `docs/ARCHITECTURE.md` §四。

---

## 一、功能清单

### 1. 页面架构

```
Dashboard (Tauri WebView 窗口)
├── 左侧导航栏（Sidebar）
│   ├── 插件管理     ← 默认页
│   └── 崩溃日志     ← 显示未读数量角标
└── 右侧内容区
    ├── 插件管理页（Plugins.tsx）
    └── 崩溃日志页（CrashLog.tsx）
```

- **路由**：React Router 两个路由，`/` 默认跳转 `/plugins`
- **窗口**：标准窗口，有标题栏，可缩放，标题 "BetterCPT Dashboard"
- **打开方式**：右键托盘图标 → "Dashboard" 菜单项 → 创建 Tauri WebView 窗口

### 2. 页面详情

#### 2.1 插件管理页（主页面）

**功能 A：插件列表**

| 列 | 说明 | 数据来源 |
|----|------|----------|
| 插件 ID | `@author/plugin-name` | `manifest.id` |
| 名称 | 显示名称 | `manifest.name`，fallback 到 id |
| Runtime | Widget / Script | `manifest.runtime` |
| 状态 | Installed / Running / Crashed / Stopped / Recovering | RuntimeRegistry |
| 内存 | Private Working Set（或 V8 heap） | 5 秒采样的 `memory_sample` 事件 |
| 崩溃 | 累计崩溃次数 | `crash_count` |
| 操作 | 按钮组（见下方） | — |

**功能 B：操作按钮（每行）**

| 状态 | 可用操作 |
|------|----------|
| Installed | 启动 |
| Running | 停止 |
| Crashed | 重启 |
| Stopped | 启动 |
| Recovering | —（禁用） |
| 所有状态 | 卸载（需确认） |

**功能 C：安装插件**

- 拖拽 `.bcpkg` 文件到列表区域（或整个页面）
- 安装时显示进度提示
- 安装成功后列表自动刷新
- `.bcpkg` 格式：zip 压缩包，内含 `manifest.json` + 插件文件
- 安装路径：Host 将文件解压到 `%AppData%/BetterCPT/plugins/<plugin-id>/`

**功能 D：顶部状态栏**

- "已安装 X 个插件，Y 个运行中"
- 刷新按钮（手动拉取快照）

#### 2.2 崩溃日志页

**功能 A：左侧文件列表**

- 从 `%AppData%/BetterCPT/logs/crash/` 读取文件列表
- 每行显示：插件 ID（从文件名提取）+ 时间戳
- 按时间倒序排列
- 未读/已读状态（本地标记）

**功能 B：右侧详情面板**

- 选中文件后展示格式化的 JSON 内容
- 字段：`pluginId`, `timestamp`, `runtime`, `error`, `stack`, `isolateState`, `crashCount`
- stack trace 用等宽字体、可滚动
- 复制按钮（复制全部 JSON）

**功能 C：操作**

- 清除全部（需确认）
- 删除选中

### 3. 全局功能

#### 3.1 断连恢复

- Tauri IPC 断开时 → 全屏半透明遮罩 + "连接已断开，正在重连..."
- 重连成功后 → 遮罩消失，重新拉取 `get_runtime_snapshot`
- Tauri 原生 `onDisconnect` 事件处理

#### 3.2 实时更新

- Dashboard 启动时：`invoke("get_runtime_snapshot")` 拉取全量
- 运行时：`listen("runtime_event")` 监听增量事件
  - `plugin_installed` → 列表新增
  - `plugin_started` → 状态更新
  - `plugin_stopped` → 状态更新
  - `plugin_crashed` → 状态更新 + 崩溃计数 +1
  - `plugin_recovered` → 状态更新
  - `memory_sample` → 内存列更新

#### 3.3 窗口生命周期

- Dashboard 窗口关闭 → Tauri WebView 销毁
- 再次从托盘打开 → 新建窗口，重新拉取快照
- v1 不做窗口位置记忆

**暗色专业风格** —— 面向开发者和高级用户，信息密度适中，操作路径短。

- VS Code 侧边栏 + 面板风格
- Windows 11 暗色主题

### 4. 组件规格

#### 4.1 侧边栏导航

```
┌──────────┐
│  🏠       │  ← BetterCPT Logo/Icon
│           │
│  ▣ 插件管理│  ← 当前页高亮（左侧蓝色竖条 + 背景加深）

│  ◉ 崩溃日志│  ← 未读角标（圆角小数字，红色背景）

│           │
│           │
│═══════════│  ← 版本号
│  v1.0.0   │

```

- 宽度：200px（固定）
- Logo 区域：48px 高，居中
- 导航项：40px 高，8px 圆角，左侧 3px 指示条
- 当前页：`bg-gray-800` + 左侧蓝色 `border-l-3 border-blue-500`

#### 4.2 插件列表表格

- 表头：`bg-gray-850`，`text-gray-400`，12px 字号
- 行：`bg-gray-850`，悬停 `bg-gray-800`，40px 行高
- 分隔线：`border-b border-gray-700`
- ID 列：等宽字体 `font-mono`，灰色文字，可复制
- 状态列：彩色圆点 + 文字
  - Running：绿色圆点 `●` + "运行中"
  - Crashed：红色圆点 `●` + "已崩溃" + 崩溃次数
  - Installed：黄色圆点 `●` + "已安装"
  - Stopped：灰色圆点 `●` + "已停止"
- 内存列：右对齐，格式化为 MB/GB
- 操作列：图标按钮组（无文字，Tooltip 显示说明）

#### 4.3 操作按钮

```
⏹ 停止 (Running 时显示)
▶ 启动 (Installed/Stopped 时显示)
↻ 重启 (Crashed 时显示)
🗑 卸载 (所有状态，需确认)
```

- 图标按钮：28×28px，`hover:bg-gray-700`，`rounded`
- 卸载确认：弹出确认对话框 "确定要卸载 @xxx/xxx 吗？此操作不可撤销。"

#### 4.4 拖拽安装区

- 位置：列表下方或覆盖层
- 样式：虚线边框 `border-2 border-dashed border-gray-600`，圆角 8px
- 高度：80px（折叠）/ 全屏半透明遮罩（拖拽文件悬停时）
- 拖拽悬停状态：边框变蓝 `border-blue-500`，背景 `bg-blue-500/10`
- 文字提示："拖拽 .bcpkg 文件到此处安装" / "释放以安装"

#### 4.5 状态栏

- 位置：内容区顶部，表格上方
- 左侧：统计文字 "已安装 5 个插件，3 个运行中"
- 右侧：刷新按钮（图标按钮，手动触发 snapshot）

#### 4.8 通知提示（Toast）

- 右下角弹出，3 秒自动消失
- 类型：成功（绿）、错误（红）、信息（蓝）
- 场景：
  - 安装成功："插件 @xxx/xxx 安装成功"
  - 安装失败："安装失败：manifest.json 格式错误"
  - 操作结果："Dock 已停止"
  - 崩溃通知：自动弹出，持续 5 秒

### 5. 交互规范

| 交互 | 行为 |
|------|------|
| 悬停表格行 | 背景色变亮，显示操作按钮（若隐藏） |
| 点击操作按钮 | 即时响应，Toast 反馈结果 |
| 拖拽文件 | 页面出现蓝色虚线边框 + 半透明遮罩提示 |
| 释放文件 | 安装 → Toast 结果 |
| 侧边栏切换 | 无页面刷新，React Router 切换 |
| 断连 | 遮罩覆盖，不丢失已有数据 |
| 重连 | 遮罩消失，静默刷新数据 |
| 窗口关闭 | 直接关闭，无保存确认 |

## 三、开发约束

- v1 不做：多窗口管理、窗口位置记忆、插件间通信
- Dashboard 不持有运行时状态，所有状态从 Host 订阅
- 所有 Rust command 必须在 `main.rs` 的 `invoke_handler` 注册
- TypeScript 不允许 `any` 类型
- 不能引入 `package.json` 之外的新依赖
